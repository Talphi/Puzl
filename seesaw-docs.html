Radius Rules

Border radius is not decorative — it signals the type of element. Don't mix contexts. These rules are intentional.

Rule: Primary CTA buttons in overlays, modals, and results always use border-radius: 999px (pill). All other buttons — nav, hero, quiz header, dashboard actions — use border-radius: 8px. No sharp corners anywhere in the system.
Value Demo Context Classes / Notes
4px
Tags, badges .ss-tag, .ss-badge
6px
Form inputs, selects, stat boxes, error messages .ss-input, .ss-select, .ss-stat, .ss-error
8px
All .ss-btn variants, nav buttons, quiz header, dashboard actions, dropdowns .ss-btn (default), applied inline for other contexts
12px
Preview cards, collection cards, scenario cards, dashboard panels .ds-preview, .coll-card, .login-box ancestor wrappers
14px
Onboarding role tiles .onb-tile
16px

24px

999px
Primary CTA buttons in overlays, modals, results. Google sign-in. Onboarding chips. .btn-login, .btn-waitlist, .btn-google-login, .onb-chip

Dark Mode

Toggle with body.dark-mode. All tokens remap automatically — brand colours switch to their on-dark WCAG AA variants. Persisted via localStorage.

Token Remapping
Token Light Dark Notes
--bg #FFFFFF #111111 Page background
--white #FFFFFF #1A1A1A Surfaces, cards, overlays
--black #111111 #F0EFE9 Primary text, buttons
--red #D62828 #FF3366 4.72:1 on #111 — AA ✓
--blue #1550A2 #5B9BF5 6.70:1 on #111 — AA ✓
--green #2B7A44 #34D399 9.82:1 on #111 — AAA ✓
--yellow #F2C200 #F2C200 11.23:1 on #111 — unchanged
